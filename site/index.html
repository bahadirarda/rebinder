Rebinder moves a local Claude Code session into a native Codex thread, then resumes it in the workspace or Git worktree where the work happened. Codex owns the conversion; Rebinder owns explicit selection, safe orchestration, and the handoff boundary.

01 / Use it today

Pick up the thread.
Change the harness.

Discover a supported local Claude Code chat, choose it interactively, and continue through Codex's native migration API in the recorded workspace. Large histories are bounded before import. No direct writes to either provider's private session store.

Discoverread only

Find the Claude session.

Choose with arrow keys and Enter. Auto uses a context-safe handoff for large chats, then opens codex resume in the source workspace.

02 / The boundary

Portability is a report,
not a promise.

A session is more than chat history. Repository state, task state, tool provenance, permissions, and provider-only capabilities all affect whether work can continue safely.

03 / Portable package

State you can inspect
before an agent starts.

The portable core validates a canonical package as ordinary files. No harness is launched, no package content is executed, and failed integrity checks stop inspection.

session-package/schema 0.1.0
  • ◆ manifest.json identity + digests
  • ├─ session.json portable identity
  • ├─ conversation.jsonl ordered graph
  • ├─ task-state.json goals + progress
  • ├─ repository-state.json revision + changes
  • ├─ workspace-state.json environment facts
  • ├─ provenance.json source + redactions
  • └─ handoff.md human-readable bridge
01

Schema first

Every canonical JSON document is validated against Draft 2020-12 before deeper checks run.

02

Integrity bound

A SHA-256 inventory binds every portable file to the manifest before its content is trusted.

03

Filesystem confined

Relative paths stay inside the package root; symbolic links and non-regular files are rejected.

04

Provenance visible

Source harness, export time, transformations, and redactions remain reviewable evidence.

Read-only commands

Validate. Inspect. Decide.

Use structured output when another tool needs to consume the package facts.

$ rebinder validate ./session-package

$ rebinder inspect ./session-package --json

04 / Release identity

Calendar versions.
Verifiable binaries.

Rebinder uses 0.YYYYMMDD.REVISION. The date identifies the release source day; the final number increments when another release comes from that day.

05 / Install

One verified
native binary.

The installer selects the matching release archive, verifies its SHA-256 digest and embedded identity, activates the binary, then checks the installed version. No package runtime required.

  • Linux x86-64 and ARM64
  • macOS Intel and Apple silicon
  • Windows x86-64
