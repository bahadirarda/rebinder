# Support

Use [GitHub Discussions](https://github.com/bahadirarda/rebinder/discussions)
for usage questions and design discussion. Use
[GitHub Issues](https://github.com/bahadirarda/rebinder/issues) for reproducible
bugs and scoped feature requests.

Security reports follow [SECURITY.md](SECURITY.md). Never post session packages,
tokens, private transcripts, or unredacted environment state in public support
channels.
